Acústica de Locales 3 herramientas
🏠
Modos Normales de Vibración
Calcula los 50 primeros modos de una sala rectangular. Criterios de Bolt, Bonello y espectro modal completo con detección de modos degenerados.
ISO 3382 · ANSI S12.2 📊
Curvas de Ruido
Evaluación del ruido de fondo según familias NC, NR, PNC, RC y NCB. Cálculo de dB(A) para DIN 4109 y veredicto por tipo de recinto.
NC · NR · PNC · RC · DIN 🎧
Auralización Paramétrica
Escucha cómo suena un audio en tres salas padrón (Control Room, Aula, Sala de Conciertos). Ajusta parámetros acústicos como T_mid, C80, STI y escucha el efecto en tiempo real.
Web Audio API · ISO 3382

Guía de Diseño: Resonadores y Difusores
Manual técnico con fórmulas, ejemplos resueltos y planimetría SVG para Resonador de Helmholtz y Difusor QRD. Incluye fórmulas con MathJax.
Helmholtz · QRD · SynthEdit 🔇
Calculadora Resonador de Helmholtz
Calculadora interactiva para diseño de panel perforado. Ingresa frecuencia, espesor, broca y profundidad — obtén porcentaje de perforación, separación y planos constructivos.
Panel perforado · SVG en tiempo real 〰️
Calculadora Difusor QRD
Diseño de difusor de residuos cuadráticos (Schroeder). Elige N7, N11 o N13. Visualización de perfil constructivo y estructura 3D isométrica en tiempo real.
N7 · N11 · N13 · 3D
Síntesis y Efectos 1 herramienta

LFO Lab — Laboratorio de Modulación
Explora AM (Tremolo), FM (Vibrato), PM (Chorus) y Ring Modulation. Controla forma de onda del LFO, Rate, Depth y escucha el resultado. Osciloscopio + espectro en tiempo real. Diseñado para complementar SynthEdit.
AM · FM · PM · Ring · Web Audio
📌 Cómo usar estas herramientas en Wix
Las herramientas de Auralización y LFO Lab usan Web Audio API y requieren ser embebidas con permiso de autoplay. En Wix, usa un elemento HTML embed con el siguiente código (reemplaza la URL con la de tu GitHub Pages):
<iframe src="https://TU-USUARIO.github.io/TU-REPO/LFO_Lab.html" width="100%" height="750px" allow="autoplay; microphone" style="border:none; border-radius:8px;"> </iframe>
Las demás herramientas (solo gráficos, sin audio) pueden pegarse directamente en el HTML embed de Wix sin necesidad de iframe externo.
